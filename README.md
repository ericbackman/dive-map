# dive-map

**[dive.ericbackman.com](https://dive.ericbackman.com)**, an interactive world
map of every scuba dive I've logged: **147 dives, 20 trips, 11 countries,
2013–2026**, plus 98 clips of what was actually down there.

Click a pin for the site, date, depth, dive type and the highlights. Three tabs:
the map, a video gallery grouped by trip, and a searchable dive log.

## Why it's built this way

No build step, no framework, no API keys. It is a static `index.html` plus one
JSON file, so it costs nothing to run and will still load in ten years.

- **Map.** Leaflet 1.9.4 from a CDN, with markercluster and ant-path
- **Tiles.** CARTO Dark Matter (free, keyless)
- **Data.** `data/dives.json`, hand-curated from my dive logs
- **Video.** YouTube embeds, hosted on the Scuba Sessions channel
- **Hosting.** Cloudflare Pages and GitHub Pages, both on push to `main`

The code cannot break in a dependency update: the CDN versions are pinned and
Leaflet carries an SRI hash. The *content* is a different story, and is the one
thing here that genuinely rots. See below.

## The videos are the fragile part

The clips live on a YouTube channel run by a separate project, which treats them
as disposable working stock. In August 2026 an audit found 23 of 116 embeds had
been deleted, including one of the four front-page highlights. Every host was
green the whole time. Nothing noticed.

So `scripts/check_video_liveness.py` now runs weekly in CI and on every change
to the data. It probes the same thumbnail endpoint the gallery draws from, so a
failure is exactly the broken tile a visitor would see:

```bash
python scripts/check_video_liveness.py
```

## The data

`data/dives.json` holds `diver`, `trips`, `bestVideos` and the `dives` array.
Videos hang off **trips**, not individual dives. Each dive:

```json
{
  "id": 6,
  "trip": "grand-cayman-2014",
  "site": "Castle Wall",
  "location": "Grand Cayman, Cayman Islands",
  "lat": 19.282, "lng": -81.419,
  "depth_m": 29.6, "duration_min": 42,
  "date": "2014-04-17",
  "type": "wall",
  "highlights": ["moray eels", "wall dive"],
  "notes": "Eels, deepest dive to date. Huge wall, variety of aquatic life.",
  "rating": null,
  "media": []
}
```

`rating` is nullable: the early logs predate my rating them. `media` is vestigial
and empty on all 147 dives.

Site types in use: `reef` (110), `wall` (12), `drift` (10), `night` (7),
`wreck` (4), `cave` (2), `cenote` (2).

Depths run 6.1–37.0 m (median 20.5 m).

Video titles were generated by an AI vision pass, so a species name is a claim
rather than a fact. A few have been corrected; a couple are still open.

## Running it locally

Any static server: there's nothing to compile:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly works too,
though some browsers block the `fetch` of `dives.json` over `file://`.

## Repo layout

```
index.html          the whole page
css/style.css       dark ocean theme
js/map.js           DiveMap module: init, markers, popups
js/travel-path.js   animated route between trips + guided tour
js/app.js           entry point: loads data, boots the map, renders tabs
data/dives.json     every dive, trip and video
data/travel-path.json  great-circle route between trips
scripts/            working tools (liveness check, log import, classification)
analysis/breathing/ dive-computer breathing-rate analysis (separate from the map)
```

`scripts/`, `analysis/` and `docs/` are working tools, not part of the deployed
site: the page only needs `index.html`, `css/`, `js/` and `data/`. `_config.yml`
keeps them off GitHub Pages.

## Notes

Coordinates are approximate site locations, not exact GPS entries: dive sites
are areas, and a few are deliberately fuzzed. Nothing here is a navigation aid;
dive with a guide and your own plan.
